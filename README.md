This is my Portfolio made with Next.js, Three.js, Framer Motion, Tailwind CSS, where I will be introducing and showcasing my projects, socials and updates.

## Have a Look:

https://space-portfolio-cyan-two.vercel.app/

## Prerequisites:

```
Node.js
Editor of your choice
A BrOWsEr
```

## Try It Yourself:

Clone the repo:
```
git clone https://github.com/MRHWCKRR/space-portfolio.git
```

Or Fork Your Own!

All content is based in page.tsx, and pictures of projects go into Public -> Projects

To run your local copy:

```
npm run dev
```
